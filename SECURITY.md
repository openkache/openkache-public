# Security policy

## Supported versions

No supported versions are currently published.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues, discussions, or pull
requests. Until private vulnerability reporting is configured for this
repository, send a private report to
[security@openstd.com](mailto:security@openstd.com).

Include, when available:

- the affected version, commit, or artifact
- the deployment environment and relevant configuration
- clear reproduction steps or a proof of concept
- the expected and observed behavior
- the potential impact
- logs or traces needed to reproduce the issue

Remove credentials, private keys, tokens, and personal data before sending a
report.
